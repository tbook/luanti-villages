# Generate villages on smoothed, planned terrain. Turn off to fall back to
# VoxeLibre's own village generation if something goes wrong.
living_villages_smooth_villages (Smooth villages) bool true
# Village holes and cliffs (#155), when smoothing is on. Holes and shafts of any
# depth are filled to the surrounding ground. A cliff between a column and a
# higher neighbor is turned into a ramp if the column has to rise no more than
# this; a taller wall is left. 0 leaves cliffs alone and fills holes only.
living_villages_cliff_rise (Largest cliff to ramp) int 4 0 32
# The most nodes one village's hole and cliff filling may write. Smaller pieces
# are done first; what does not fit is left as it was.
living_villages_hole_budget (Hole filling node budget) int 60000 0 1000000

# Villagers wear grass they keep walking over into paths (#12).
living_villages_natural_paths (Natural paths) bool true
# Walks over one grass block before it becomes a path.
living_villages_path_wear_up (Path wear threshold) float 8
# A path made this way turns back to grass when its count fades below this.
living_villages_path_wear_down (Path regrow threshold) float 3
# Seconds for a block's count to fade by one (default: one game week).
living_villages_path_decay_period (Path fade period) float 8400
# Keep VoxeLibre's generated paths between village buildings. Off leaves
# villages as grass, and villagers wear their own paths (see above).
living_villages_generated_paths (Generated village paths) bool false
# What a step on a trip (to bed, work, tavern, bell, church) counts for;
# a step of aimless wandering counts for 1.
living_villages_path_trip_weight (Path trip step weight) float 3

# Route planning runs a few milliseconds of every server step, shared between
# villagers waiting for a route (#162). More means routes arrive sooner and
# steps run longer.
living_villages_route_budget_ms (Route planning budget per step, ms) float 4 0.5 50
# How far from its start (in nodes, each axis) the route planner searches. A
# target farther than this is still reached: the search widens to cover it,
# with a margin of 16, up to a fixed cap of 128 whatever this is set to.
living_villages_route_range (Route planner range) int 48 8 96
# The most positions one route search expands before giving up.
living_villages_route_max_nodes (Route planner node cap) int 4096 256 32768

# Game days a villager child takes to grow up (#177). VoxeLibre's own is
# about a minute. Counted in time the child is loaded and active, so it
# pauses while no player is near. Feeding a child its food still
# shortens it. The child also grows in size as it ages. A game day lasts
# 86400 / time_speed seconds; with time_speed 0 (frozen clock) the default
# of 72 (1200 s) is used, so children still age.
living_villages_child_grow_days (Child growth time, game days) float 12 0.1 100

# Share of newly generated small houses (the shepherd's hut) built without
# their loom (#223). A loomless house has a bed and no workstation, so its
# villager starts unemployed and takes another free job. The choice is fixed by
# the house's position and the world seed. 0 builds every house as stock, 1
# builds none with a loom. Existing villages are unchanged.
living_villages_loomless_house_chance (Share of small houses without a loom) float 0.5 0 1

# Sheep each shepherd with a loom keeps and herds (#215): they follow it about the
# village by day and are left to graze while it is at church, the bell, the tavern or
# in bed. 0 turns shepherds' flocks off, sheep already marked are then let go, and
# shepherds no longer take their grazing walks about the bell in the work stage.
living_villages_flock_size (Sheep per shepherd) int 5 0 5
# How far beyond the village's farthest building a shepherd leads its flock in the work
# stage (#249). Out in the field it walks to a spot 15 to this many nodes past the farthest
# door or bed (measured from the bell, scanned in up to 4 passes over what is loaded, 45-60 from the bell when no building is seen; a player's house counts), stands 20-30 s,
# then walks about 10 nodes on, and so on, at the normal walking pace. A value under 20 counts
# as 20. Always within 90 of its loom (not bounded by its bed: far_trips.lua keeps vanilla from
# sending it home); where that leaves no room it grazes as far as it allows, or among the
# buildings. Villagers no player is within 48 nodes of stand still, so a shepherd far out waits
# for a player to walk out. 0 keeps every stop in the village (within 20 of the bell).
# Before #249 this was the distance from the bell: an old value now means a margin.
living_villages_flock_range (Shepherd grazing range) int 30 0 60
# On the morning stage some idle villagers walk to the village well and stand
# about it for a while (#11). Atmosphere only.
living_villages_well_hangout (Villagers gather at the well) bool true

# A player who sits at a tavern table while the keeper is on duty is served a meal on the
# plate, which feeds a little (#19). Once per player per tavern per game day. Atmosphere
# and a small benefit; the keeper's trades are unchanged.
living_villages_player_meals (Players are served a meal at tavern tables) bool true

# Idle villagers standing near each other sometimes stop and face one another in
# twos and threes for a few seconds, as if talking (#242). Atmosphere only.
living_villages_conversation (Villagers converse) bool true
